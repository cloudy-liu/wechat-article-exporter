# Prioritize Markdown and HTML Exports

The first desktop release will treat Markdown and HTML as the core export formats. Excel, JSON, and TXT should be preserved as auxiliary formats when practical, while Word and PDF are deferred so they do not delay the local collection and archival workflow.

**Consequences**

- Export UI should make Markdown and HTML the primary actions.
- Article and album export pipelines must be reliable for Markdown and HTML before other formats are optimized.
- PDF and Word compatibility work can happen after the desktop app proves the core local workflow.
