# Legacy Web App

The existing Nuxt/Nitro web implementation is retained as a Legacy Web App migration reference.

It is no longer the active product target. New product work should happen in the Desktop Workspace at `apps/desktop`.

Use this reference to preserve desktop-relevant behavior from the Original Feature Baseline:

- Target account management
- Account article download
- Single article download
- Album download
- Settings that make sense for local desktop use

Do not use this reference to carry forward web-service-only concerns such as public APIs, public proxy operations, hosted deployment, analytics, sponsorship/support pages, or developer/debug pages.
